# Depo  `(storage)`  

Hammadeler; rüzgar ve kötü hava şartlarından korunmaları için depoya saklanırlar. Depoda herzaman yeterince yer olduğu kontrol edilmelidir, aksi halde önemli hammadeler kaybolabilirler. Maalesef hammaddeleriniz yağmacılara karşı güvende değiller. Onları saklamak için ayrıca Gizli Depo yapmalısınız.

**Maksimum seviye:** 50  
**Gereksinimler:** yok
