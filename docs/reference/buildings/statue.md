# Anıt  `(statue)`  

Muhteşem bir heykel, şehrin merkezindeki meydanda durur ve şehir halkına sürekli sizin muazzam büyüklüğünüzü hatırlatır. O heykel savaşçılarınızı onurlandırır. Heykel sayesinde sur %50 güçlenir. Ancak bütün diğer binalar tamamen geliştirildiğinde inşa edilebilir.

**Maksimum seviye:** 1  
**Gereksinimler:** Kale (Sv 50), Değirmen (Sv 50), Oduncu Kampı (Sv 50), Taş ocağı (Sv 50), Maden ocağı (Sv 50), Depo (Sv 50), Gizli Depo (Sv 30), Market (Sv 30), Kışla (Sv 30), Katır çiftliği (Sv 30), Simyager (Sv 5), Köşk (Sv 10), Kuyumcu (Sv 5), Sur (Sv 20)
