# Kale  `(main)`  

Kale, köyün kalbidir. Savaşlar sırasında vatandaşların güvenliğini sağlamasının yanında, usta ve inşaatçıların yeni binaları yapmak ve var olanları geliştirmek için hep birlikte çalıştığı yerdir. Daha büyük kale, daha fazla inşaatçının burada çalışabilmesini sağlar. Bunun anlamı binaların daha hızlı inşa edilebilmesidir. Kale 15. seviyeye ulaştığında, binaları yıkabilirsiniz.

**Maksimum seviye:** 50  
**Gereksinimler:** yok
