# Sur  `(wall)`  

Güçlü surlar sayesinde vatandaşlarınız aç kurtlardan ve saldıran diğer düşmanlardan korunurlar. Köy savunulacağı zaman surun gücü (kademesine bağlı olarak), köydeki birliklerinizin de gücünü etkiler.

**Maksimum seviye:** 20  
**Gereksinimler:** Kışla (Sv 1)
