# Değirmen  `(farm)`  

Alanın verimliliği değirmene bağlıdır. Un, değirmencinin vatandaşlarınızı beslemesini sağlar, öyle ki, krallıkta hiç kimse açlıktan ölmek zorunda kalmaz. Tüm işçileriniz ve askerleriniz beslenmek zorundadır. Bu nedenle sadece besleyebildiğiniz kadar kişi çalıştırabilirsiniz.

**Maksimum seviye:** 50  
**Gereksinimler:** yok
