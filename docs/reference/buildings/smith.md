# Kuyumcu  `(smith)`  

Kuyumcuda yeni Kontları göreve atamak için gerekli altın zırhları üretebilirsin. Tabii Kontun görevi yükseldikçe daha gösterişli altın zırhlar istemeye başlayacağından her seviyedeki altın zırhında maliyeti ona göre artar.

**Maksimum seviye:** 5  
**Gereksinimler:** Köşk (Sv 1)
