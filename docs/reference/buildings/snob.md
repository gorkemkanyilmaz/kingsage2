# Köşk  `(snob)`  

Kontlar, krallığının gündelik işlerini senin adına yoluna koyan sadık vatandaşlarındırlar. Eğer yeni bir şehrin işlerini de üstlenecek olurlarsa devlet erkini layıkıyla temsil edebilmek için altından zırh isterler. Bu altın zırhları kuyumcuda imal edebilirsin.

**Maksimum seviye:** 10  
**Gereksinimler:** Simyager (Sv 5)
