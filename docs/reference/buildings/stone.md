# Taş ocağı  `(stone)`  

Taş ocağında, devasa kaya parçaları parçalanıp işlenerek taş bloklara dönüştürülür. Bu taş bloklar, bina inşasında veya kışlalarda asker üretiminde kullanılır. Taş ocağını geliştirdiğin ölçüde daha çok taş işçisi çalıştırabilir ve daha hızlı taş blok üretebilirsin.

**Maksimum seviye:** 50  
**Gereksinimler:** yok
