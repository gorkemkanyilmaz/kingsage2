# Simyager  `(garage)`  

Simyagerin mutfağında harikulade şeyler üretilir. Bilgi mücevherini araştırırken, kötü kokulu karışımların yanında, bir çok faydalı şey de bulacaksınız. Laboratuvarınız büyüdükçe, araştırmalarınız daha başarılı olacak.

**Maksimum seviye:** 5  
**Gereksinimler:** Kışla (Sv 5)
