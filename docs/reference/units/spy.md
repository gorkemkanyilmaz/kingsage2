# Casus  `(spy)`  

Casusların gücü, savaşta yalan söylememeleridir. Ayrıca gecenin karanlığında düşman köylerini gözetlemek için sokulurlar. Daha fazla casus, daha detaylı casusluk raporu hazırlayacaktır.
