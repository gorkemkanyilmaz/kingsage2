# Muhafız  `(sword)`  

Muhafızlar sağlam kalkanları ve sarsılmak bilmez onurlarıyla tanınırlar. Krallarını ve insanlarını korumak için korkusuzca bütün düşmanların karşılarında (güçlerine bakmaksızın) dururlar. Muhafızlar yürüyen askerlere karşı uyguladıkları iyi savunmalarıyla bilinirler.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 10 |
| Eğitim maliyeti (Taş) | 30 |
| Eğitim maliyeti (Demir) | 80 |
| Vatandaş | 1 |
| Hız | 5.5 Alan başına dakika |
| Taşıma kapasitesi | 15 |
| Saldırı değeri | 100 |
| Savunma — Piyade | 300 |
| Savunma — Süvari | 100 |
| Savunma — Okçu | 200 |
| Gereksinimler | Kışla (Sv 1) |
