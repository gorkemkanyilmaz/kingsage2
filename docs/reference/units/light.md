# Akıncı  `(light)`  

Çok uzak mesafelerden dahi düşmanlar akıncıların dalgalanan sancaklarını görürler. Bu hızlı savaşçılar oldukça deneyimlidirler. Hızlı ve güçlü bir şekilde savaşın ortasına sürebilirler. Eğer hızlı bir şekilde kuşatmalar ve akınlar icra etmek istiyorsanız bu savaşçıları kullanmanız kaçınılmaz olur.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 100 |
| Eğitim maliyeti (Taş) | 100 |
| Eğitim maliyeti (Demir) | 300 |
| Vatandaş | 4 |
| Hız | 2.5 Alan başına dakika |
| Taşıma kapasitesi | 80 |
| Saldırı değeri | 900 |
| Savunma — Piyade | 200 |
| Savunma — Süvari | 300 |
| Savunma — Okçu | 300 |
| Gereksinimler | Kışla (Sv 7) |
