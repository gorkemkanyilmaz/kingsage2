# Mancınık  `(kata)`  

Mancınık ölümcül bir tekniğe sahip: Sapanları düşmanlarına en ağır kayaları fırlatabilecek şekilde tasarlanmış. Aynı zamanda binaları da bombalayabilir. Buna rağmen kendini savunamadığı için muhafıza ihtiyaç duyar.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 600 |
| Eğitim maliyeti (Taş) | 200 |
| Eğitim maliyeti (Demir) | 200 |
| Vatandaş | 8 |
| Hız | 7.5 Alan başına dakika |
| Taşıma kapasitesi | 0 |
| Saldırı değeri | 500 |
| Savunma — Piyade | 400 |
| Savunma — Süvari | 100 |
| Savunma — Okçu | 200 |
| Gereksinimler | Kışla (Sv 25) |
