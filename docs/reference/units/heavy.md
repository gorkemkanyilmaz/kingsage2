# Kara Şövalye  `(heavy)`  

Kara Şovalyelerin çevresini kötülüğün kokusu sarmıştır. Gören herkese korku ve dehşet saçarlar. Onların tek kelime ettiğini veya isimlerinin zikredildiğini kimse duymamıştır. Hiç bir zaafları yoktur. Ancak maliyetleri aşırı derecede fazladır.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 300 |
| Eğitim maliyeti (Taş) | 100 |
| Eğitim maliyeti (Demir) | 500 |
| Vatandaş | 6 |
| Hız | 2.75 Alan başına dakika |
| Taşıma kapasitesi | 50 |
| Saldırı değeri | 600 |
| Savunma — Piyade | 1500 |
| Savunma — Süvari | 1000 |
| Savunma — Okçu | 1000 |
