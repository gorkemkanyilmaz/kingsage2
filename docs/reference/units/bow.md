# Okçu  `(bow)`  

Kartal kadar keskin gözleri ve sivri uçlu oklarıyla, uzak mesafeden ölümcüldürler. Onlar, saldırı veya savunma ordunuzda sizi destekleyebilirler.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 160 |
| Eğitim maliyeti (Taş) | 80 |
| Eğitim maliyeti (Demir) | 80 |
| Vatandaş | 1 |
| Hız | 4.5 Alan başına dakika |
| Taşıma kapasitesi | 10 |
| Saldırı değeri | 150 |
| Savunma — Piyade | 400 |
| Savunma — Süvari | 150 |
| Savunma — Okçu | 100 |
| Gereksinimler | Kışla (Sv 5) |
