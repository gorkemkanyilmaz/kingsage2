# Köy Koruyucusu  `(farmer)`  

Asker eğitmeye para ve zamanın yoksa, çiftçiler kendilerini sivri ve keskin aletleriyle koruyacak. Tek başlarına ciddiye alınacak bir rakip olmasalar da büyük gruplar halinde saldırdıklarında piyade ve süvarilere önemli zararlar verebilirler.

| Özellik | Değer |

| Eğitim maliyeti (Odun) | 10 |
| Eğitim maliyeti (Taş) | 3 |
| Eğitim maliyeti (Demir) | 7 |
| Vatandaş | 1 |
| Hız | 5 Alan başına dakika |
| Taşıma kapasitesi | 5 |
| Saldırı değeri | 20 |
| Savunma — Piyade | 40 |
| Savunma — Süvari | 30 |
| Savunma — Okçu | 5 |
| Gereksinimler | Kışla (Sv 1) |
