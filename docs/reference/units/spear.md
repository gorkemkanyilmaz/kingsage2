# Silahtar  `(spear)`  

Bir şovalye silahtarı olmadan ne yapar! Fakat silahtarlar, şovalyeleri olmadan da çok faydalı destek birimleridir. Atlarla araları iyidir, çok fazla silahları olmamasına rağmen, atlı birliklere karşı kendilerini koruma becerisine sahiptirler.
