# Şahmerdan  `(ram)`  

On adamın gücüyle çelik alnını vuracak bir şahmerdana uzun süre dayanacabilecek sur yoktur. Fakat ağırlığı çok fazla olduğundan, çok yavaş hareket edebilir.

| Özellik | Değer |
|---|---|
| Eğitim maliyeti (Odun) | 500 |
| Eğitim maliyeti (Taş) | 100 |
| Eğitim maliyeti (Demir) | 200 |
| Vatandaş | 5 |
| Hız | 7.5 Alan başına dakika |
| Taşıma kapasitesi | 0 |
| Saldırı değeri | 100 |
| Savunma — Piyade | 100 |
| Savunma — Süvari | 200 |
| Savunma — Okçu | 20 |
| Gereksinimler | Kışla (Sv 20) |
